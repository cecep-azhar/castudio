## CAStudio v0.1.0 — Initial Sovereign AI Content Engine Release

### Highlights
- **Sovereign Local-First Desktop Content Engine**: Built with Tauri v2, Rust 2024, Svelte 5, and SQLite.
- **Content Builder**: Modular Visual Block Canvas + Raw Markdown editor.
- **E-Book Studio**: Outline Architect with EPUB, HTML, and Markdown export capabilities.
- **Instagram Suite**: Carousel 4:5 (1080x1350) with 1-click canvas PNG download, Reels 9:16 script generator, and Caption Cleaner.
- **Repurposing Launch Pack**: Instant 1-click generation of Thread, Email, and Slide formats.
- **Pitchdeck & Closing Suite**: 10-slide VC deck generator and SPK Contract Generator.
- **Prompt Studio**: Built-in prompt library for Software Dev, QA, Media, and Content workflows.
- **Ultra-lightweight footprint**: 7.1 MB release binary, <35 MB RAM runtime.
